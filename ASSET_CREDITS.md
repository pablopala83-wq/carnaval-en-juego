## Identity

The SVG wordmarks implement the approved typographic direction in vector outlines: CARNAVAL, EN JUEGO in a burgundy block and a separated yellow accent. The circular avatar contains the full name. The PWA mark contains only CEJ, with no slash or yellow line beside the J.

Exact brand colors: charcoal `#121212`, cream `#F3EBDD`, burgundy `#9E2A2B`, yellow `#D9A441`. Outlined lettering is based on the installed URW Nimbus Sans Narrow Bold Oblique typeface. The app uses system sans-serif and serif fonts; no external font request is required.
